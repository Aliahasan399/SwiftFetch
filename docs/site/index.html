SwiftFetch

A Windows desktop download manager built with Tauri, React, TypeScript, and Rust.

Add an HTTP or HTTPS link to queue a download, pause or retry it, set transfer limits, or supply a trusted checksum. SwiftFetch works without a hosted account or queue service and keeps its state locally on your Windows account.

What it does

  • Resumable transfers

    The transfer engine uses multiple connections for eligible files and falls back to one stream when a server ignores range requests. SQLite stores segment checkpoints so an interrupted transfer can be reconciled and resumed.

  • Local queue and history

    Queue state, settings and download history are kept in the current user's %APPDATA%\swiftfetch directory by default. Priorities, scheduling windows and diagnostics are built in.

  • Explicit control

    Task details offer collision decisions, segment ranges and checksum state. Files open only after an explicit user action, and tray controls can pause work or exit safely with a cancellable shutdown countdown.

  • Optional browser handoff

    An optional extension can send a selected URL to the local app through Windows Native Messaging. It requires desktop opt-in and per-user setup, and does not forward cookies or credentials.

Local-first by design

There is no required account and no telemetry upload. The app makes network requests only to the download source, configured proxies and redirects accepted by its URL policy. Clipboard capture is off by default. See the Privacy page for the full local-first behavior.

Permitted use

Use SwiftFetch only for content you have permission to download. Respect copyright, authentication, DRM, paywalls, website access policies and server rate limits. SwiftFetch must not be represented as providing circumvention capabilities.

Code signing policy

The signing policy, required attribution, roles and release-approval process are documented on the dedicated Code signing policy page. Current Windows installers are unsigned preview candidates.
