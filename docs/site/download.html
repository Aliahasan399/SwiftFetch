System requirements

  • Windows x64; local verification platform is Windows 11 x64.
  • Microsoft Edge WebView2 Runtime.
  • For building from source: Microsoft C++ Build Tools with the Desktop development with C++ workload, Rust 1.98.0 targeting x86_64-pc-windows-msvc, Node.js 24 or newer, and Python 3.12.

Build from source

Until a signed release is published, the reviewed source can be built locally. From the repository root on Windows:

npm ci
npm run tauri dev

Verification and packaging scripts are ./tools/verify.ps1, ./tools/build-windows.ps1 and node tools/smoke-desktop.mjs. The build produces a desktop binary and Windows installers in src-tauri/target/release/.

Builds do not invent publisher signing credentials or update endpoints. Signed updates and rollback require the release owner to provide signing keys and HTTPS endpoints at build time; see Documentation.

A note on expectations

Download speed depends on the source, connection, server policies, storage and device resources. Multiple connections are an optimization and do not guarantee a particular improvement. Checksum and antivirus results have limited meanings and do not guarantee that downloaded content is safe. Only open completed files you trust.
