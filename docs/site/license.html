License

The distribution license for SwiftFetch has not been finalized.

Proposal

The owner's proposed license is GPL-3.0-or-later. This proposal is pending a dependency compatibility audit and must not be presented as the final project license until that audit completes and the owner approves the selection.

The release-readiness record states that a project distribution license has not been selected and no open-source license has been assigned on the owner's behalf. The license page will be updated when the audit and owner approval are complete.

Pending audit

The dependency notice inventory collected 338 dependencies with an SPDX inventory and available license text. Seven package roots lacked license text and require review as part of the compatibility audit. Third-party notices must be reviewed before distribution.

Terms draft

docs/TERMS-DRAFT.md is a product-use draft. It is not a selected software license and is not legal advice. Before distributing the project, the release owner must select the distribution license, identify the publisher, and approve the applicable terms, warranty and support position, and third-party attribution.

Permitted use in that draft: use SwiftFetch only for content you are permitted to download, and respect copyright, authentication, DRM, paywalls, website access policies and server rate limits.

Download cost
