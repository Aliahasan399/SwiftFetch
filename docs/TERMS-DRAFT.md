# SwiftFetch permitted-use and distribution draft

Use SwiftFetch only for content you are permitted to download. Respect copyright,
authentication, DRM, paywalls, website access policies and server rate limits.
The software must not be represented as providing circumvention capabilities.

Download speed depends on the source, connection, server policies, storage and
device resources. Multiple connections are an optimization and do not guarantee
a particular improvement. Checksum and antivirus results have limited meanings
and do not guarantee that downloaded content is safe.

This document is a product-use draft, not a selected software license or legal
advice. The release owner must select the distribution license, identify the
publisher, and approve the applicable terms, warranty/support position and
third-party attribution before distributing the project.
